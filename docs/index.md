# Checkers

Checkers is American checkers for iPhone. Play against the computer at three levels, Easy,
Medium and Hard, or with a friend on the same phone. The app works fully offline, with no
account and no analytics.

## Getting help

To report a problem or ask a question, open an issue at
[github.com/iglooo101/checkers/issues](https://github.com/iglooo101/checkers/issues). Opening an
issue needs a GitHub account; no email address is published for support.

Please say which iPhone and which version of iOS you use, what you did, what you expected and
what happened.

## Privacy

Checkers collects no data. Read the [privacy policy](privacy/).
